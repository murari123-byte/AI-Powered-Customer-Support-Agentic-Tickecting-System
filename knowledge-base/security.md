# Security and suspicious activity

## If you think someone else is using your account

Act right away:

1. Change your password (Settings > Security > Change password).
2. Click "Sign out of all devices" on the same page.
3. Turn on two-factor authentication.
4. Open a ticket with the category Security. The Security Team answers security tickets within
   1 hour, 24 hours a day.

## Emails pretending to be TaskFlow (phishing)

TaskFlow will never ask for your password by email or chat. Real emails from us only come from
addresses ending in @taskflow.example. If you get a suspicious email, don't click its links:
forward it to security@taskflow.example and delete it.

## Leaked API keys

If an API key was exposed (for example pushed to a public code repository), revoke it immediately
in Settings > API keys and create a new one. Revoked keys stop working within one minute.

## Reporting a vulnerability

Found a security bug? Email security@taskflow.example with the steps to reproduce it. Please do not
share it publicly until we have fixed it. We reply within 2 business days.

## How we protect your data

All data is encrypted in transit (TLS 1.2 or higher) and at rest (AES-256). Backups are made every
day and kept for 35 days.
